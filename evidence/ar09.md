# AR09 · Find, cancel and diagnose work in the installed product

Slice 2026-11-24 · branch `backend` · `merger` history · AR-001 §AR09.

## Goal

The owner has one shared Activity surface: a bounded union of durable role jobs
and delegated runs, with a signed keyset cursor, typed progress, real cancel,
diagnosis and review navigation. Injected state survives navigation and
restart; manual work (editors, deterministic gates, settings) stays usable
under load and provider failure.

## What changed

- `migrations/0036_inference_activity.sql`: `(epoch, updated_at DESC, id)`
  indexes for `durable_job` and `agent_run` so either side of the activity
  union streams in the exact page order.
- `inference/activity.rs` (new): `GET /api/v1/agent/activity` — owner-only
  union of jobs and runs ordered by `(updated_at DESC, kind DESC, id DESC)`.
  - Signed keyset cursor: base64url payload + HMAC-SHA256 under the workspace
    command secret (domain `activity-cursor`), bound to epoch, expiry (600 s)
    and page size; forged/foreign/stale cursors fail `400` with
    `ACTIVITY_CURSOR_INVALID`.
  - Per-side keyset conditions keep pagination exact across both tables.
  - Typed DTO: `kind, id, role, status, state_revision, attempt_count,
    progress, scope, error_code, review_ref, updated_at`; no transcript,
    output, candidate or provider rows.
  - Review references: coach report / template candidate / interviewer
    candidate / brief scope / proposal batch / match run, and delegated-run
    review refs derived from committed tool intents only.
  - Private strong ETag (`"parley-activity-<sha256>"`) that changes when the
    union changes.
  - Closed filter validation per kind (job vs run status sets).
- `inference/mod.rs`, `lib.rs`: module + route registration; `/activity` SPA
  shell route added.
- `contract/openapi.yaml` + regenerated `web/src/api/generated.ts`:
  `listAgentActivity`, `AgentActivityItem/List/Progress`.
- `web/src/api/client.ts`: typed `getActivity`.
- `web/src/app/inference/activity.ts`: shared session-owned reconciler
  (`observeActivity`) — 2 s while any listed item is active, 8 s when
  terminal, stops while hidden, refreshes on focus and on
  command/entity/workspace event commits, fences on epoch change.
- `web/src/app/AgentActivity.vue` (new): keyboard-accessible list, filters,
  pagination, inline detail (job DTO, run status + plain-text transcript),
  real cancel (`POST /jobs/{id}`, `commands.cancelRun`), typed review
  navigation.
- `web/src/app/tabs.ts`, `router.ts`, `AppShell.vue`: Activity tab after
  Settings (mandated product-tab order untouched).
- `web/src/features/settings/DelegatedRuns.vue`: runs list now consumes the
  shared reconciler (`kind=run`); its own `setInterval` polling loop, SSE
  notify and per-tick status reads are gone (reads are data-driven).
- `web/e2e/mock-api.ts`: `/agent/activity` mock implementation, job cancel,
  hung (`hang`) and provider-failed (`fail`) run scenarios.
- `web/e2e/ar09.spec.ts`: two browser cases for both projects.
- `crates/parley-service/tests/ar09.rs`: three integration tests.
- `contract/fixtures/ar09/ar09/`: `listAgentActivity.valid.json` /
  `listAgentActivity.invalid.json`.
- `contract/coverage.yaml`: ar09 rows; `ci/migrations.py`: ar09 owns 0036.
