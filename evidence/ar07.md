# AR07 evidence — qualified embeddings, calibration and the matcher through the worker

## Slice exit criteria

- **One pinned worker transport even for embeddings.** `Execute::Embed` /
  `Completion::Embed` are real protocol modes: the worker advertises the
  `embed` capability, observes the embedding tag/digest through the same Unix
  relay, validates response order, exact declared dimensions and finite
  values, and the relay only admits the embed mode's path classes
  (`GET /api/version`, `GET /api/tags`, `POST /v1/embeddings`). No Rust code
  opens a model stream.
- **Recipe-bound cache and calibration.** Vectors and trusted thresholds bind
  to a canonical recipe digest (profile revision, observed embedding digest,
  dimensions, scoring-config digest). Legacy cache rows are disposed; legacy
  calibration rows stay readable but can never satisfy a real recipe query.
  A new model, dimension or scoring configuration can never reuse old
  artifacts.
- **One logical match lease, bounded batches.** The matcher admits at most
  4,096 eligible resources, plans deterministic cache misses into frame-safe
  batches (≤16 inputs), commits completed batches under the writer fence and
  only then ranks with trusted thresholds. A second owner run reuses verified
  vectors without re-embedding.
- **Offline `parley calibrate-matching`.** The CLI runs the reviewed E-match
  fixture under the workspace lock and the same worker transport, trains a
  per-kind threshold on the training split (F1-max, higher threshold on
  ties), evaluates on the held-out split and commits trusted rows only when
  the RFC-0001 floors (gold-in-top-3 ≥ 0.80, correct no-match ≥ 0.90) pass.
  No public raw calibration write exists.
- **The Coach keeps assessment truth.** The contextual Coach classifies an
  assessment as current, missing or stale from the profile store and the
  recipe-bound calibration set; a model change without a refresh is stale,
  never a fabricated no-match.
- **Obsolete direct embedding/catalog clients removed.** `writing.rs` and
  `writing_jobs.rs` no longer contain TCP catalog probes or raw embed HTTP
  decoders; the matcher dispatches exclusively through the inference port.

## Results

- `ar07_matcher_embeds_through_worker_and_commits_recipe_bound_cache` — pass.
  Real worker embed executions (multiple batches), recipe-bound cache commit,
  trusted calibration through the real offline path, a successful owner match
  and a second run that re-uses cached vectors with zero additional embedding
  POSTs.
- `ar07_embed_shape_mismatch_fails_closed` — pass. A scripted upstream
  returning 4-dimensional vectors against an 8-dimensional qualified profile
  fails the job closed with no match_run published.
- `ar07_scoped_match_cannot_read_ungranted_resources` — pass. A delegated run
  granted only one resource admits a matcher child whose input contains
  exactly that resource, and the run completes through the real worker.
- `ar07_unqualified_embed_profile_fails_closed_but_manual_survives` — pass.
  Without the embed identity the matcher fails closed as
  `CAPABILITY_UNQUALIFIED`, leaving manual selection available.

## Browser proof

`web/e2e/ar07.spec.ts` covers unverified → verified → uncalibrated (422
`CALIBRATION_REQUIRED`) and the calibrated flow on the mock project, plus the
Coach assessment truth flip (current → stale after a model change). The Rust
project asserts the fail-closed capability state on a host without a
qualified pairing.

## Qualification still required

- Live measured pairing quality on the qualified reference host is not
  claimed here; `scripts/qualify-inference --slice ar07 --cohort matching`
  remains the release blocker for model quality.
- The spec's `scripts/qualify-inference` harness is not yet present in this
  repository (see `evidence/ar01.md`).
- The bundled `eval/match-v1.json` fixture has not been reviewed by a human
  owner; its digest binds thresholds once reviewed.
