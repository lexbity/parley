# P01 · Party sheet rename, shared selection, focus edits, notes and dossier

Qualified by `crates/parley-service/tests/p01.rs` and `web/e2e/p01.spec.ts`
(mock and rust projects). Covers:

- Tab rename Leads → Parties with `/leads` deep links preserved as aliases.
- Directory rows carrying the owner-editable focus and the strong entity ETag;
  typed entity PATCH under If-Match (stale → 412, blank names → 422).
- Canonical entity notes (UTF-8/LF) with an independent notes revision; stale
  notes writes → 412; idempotent replay returns the original commit.
- Inspector dossier: direct attributed links, open opportunities, files and
  resources used by visible opportunities, each bounded and ID-deduplicated.
- Session capabilities advertise `party.sheet`, `party.notes`,
  `party.dossier`.
