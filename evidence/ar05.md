# AR05 evidence — delegated actions through the contained Pi worker

## Slice exit criteria

- **One authoritative delegated path.** `agent_runtime/mod.rs` no longer owns a
  model decoder. It claims a leased run, journals the complete ordered tool
  list in the writer before accepting an assistant turn, and executes each
  ordinal through the existing registry validators, operation-key namespace and
  receipts. The former `agent_runtime/provider.rs` is deleted.
- **Real packaged worker.** `agent/src/delegated.mjs` embeds pinned Pi Agent
  Core 1.6.0 over the same UDS relay and closed JSONL codec as the role worker.
  It receives only canonical host messages and frozen descriptors, halts on
  suspension, and reconstructs history on resume. No SDK session file, ambient
  tool, credential or owner session reaches the worker.
- **Waits release the lane.** A `waiting_job` or `waiting_owner` result is
  persisted with a bound originating intent, the worker is reaped and the
  dispatcher lane is free. A second scoped run reaches success while the first
  is parked, and the first resumes with only its unexecuted ordinal.
- **Cancellation and completion are lease-fenced.** A cancel committed while a
  provider reply is held cannot publish a late assistant turn or tool result;
  replay of a start key returns the original run and a committed tool has
  exactly one audit effect.

## Results

- `ar05_packaged_pi_run_commits_one_scoped_read_and_finishes` — pass. Real
  contained Node/Pi worker, profile and catalog probes, host-issued ordinal
  keys and a completed scoped read are observed end to end.
- `ar05_lost_ack_committed_tool_is_reconciled_once` — pass. One committed
  effect and one durable intent after a start-key replay.
- `ar05_foreign_tool_and_scope_never_reach_business_mutation` — pass.
- `ar05_partial_batch_waits_releases_lane_and_resumes` — pass. Two ordinals are
  journaled together; the first parks on a real child job, a second run
  succeeds while it waits, and resume replays only the second ordinal.
- `ar05_cancel_and_completion_have_one_writer_order` — pass.
- `ar05_browser_follows_a_delegated_brief_to_review` and
  `ar05_browser_cancel_persists_across_reload` — pass on both browser projects;
  the Rust project records the typed fail-closed capability state where no
  local pairing is provisioned.

## Qualification still required

This host is not the qualified Ubuntu 24.04 reference. The integration fixture
uses a debug-only, explicitly verified bundle built from the pinned Node 26.12.0
and the shipped worker source; release binaries keep only the build-time
manifest digest. A reviewed local Ollama pairing, immutable model tags,
no-egress proof and the `scripts/qualify-inference --slice ar05 --cohort
delegated` evidence remain release blockers and are not claimed here. Browser
fixtures and scripted upstreams are not substitutes for that qualification.
