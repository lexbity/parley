# S01 executed evidence

RFC-0003 S01 is implemented in this checkout. The complete cumulative gate and
the per-slice proof were run on 2026-11-21. This records S01 only; it does not
qualify the full Parley product or later slices.

## Results

- `scripts/check-slice s01` — passed. Rust format, Clippy, workspace tests,
  Vue typecheck, zero-warning lint, component tests, production Vite build,
  release launcher smoke, disk check, architecture check, Rust and web coverage
  ratchets, contract fixtures/generated types, migrations and Vite manifest.
- `scripts/prove s01` — passed. Three Rust S01 integration tests and one
  Playwright journey each against the independent fixture HTTP service and the
  Rust/SQLite service; traceability IDs matched executed test names.
- Web line coverage was 100.00%, retaining the committed baseline.
- `scripts/absent 'localStorage|sessionStorage'
  web/src/features/resources/ResourceEditor.vue` — passed.
- `git check-ignore devdocs/Parley-screenflow.html` — confirms the prototype
  remains ignored.

## Reviewable implementation

- Workspace service and HTTP authority:
  `crates/parley-service/src/lib.rs`.
- One-workspace launcher and second-launch handoff:
  `crates/parley-cli/src/main.rs`.
- Durable workspace schema: `migrations/0001_workspace.sql`.
- Production API client and generated OpenAPI types:
  `web/src/api/client.ts`, `web/src/api/generated.ts`.
- Resources shell/editor: `web/src/app/AppShell.vue` and
  `web/src/features/resources/ResourceEditor.vue`.
- Independent dev/test HTTP fixture: `web/mock/server.mjs`.
- Rust tests: `crates/parley-service/tests/s01.rs`.
- Component and client tests: `web/src/app/AppShell.spec.ts`,
  `web/src/api/client.spec.ts`, and
  `web/src/features/resources/ResourceEditor.spec.ts`.
- Browser journey: `web/e2e/s01.spec.ts`.
- Contract and trace: `contract/openapi.yaml`,
  `contract/fixtures/s01/resources/`, and `contract/coverage.yaml`.

## Limits

The HTML prototype is excluded from production output and its session storage
is not used by the editor. Screen reader checks, signed native packages,
cross-platform OS picker/clipboard checks and later user journeys remain work
for their owning qualification slices. A passing S01 gate is not a complete
product conformance claim.
