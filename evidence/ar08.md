# AR08 · Compose and lint with owner review, then remove the last direct clients

Slice 2026-11-24 · branch `backend` · `merger` history.

## Goal

Composer and Linter run through the packaged structured worker. Every chat
role and the embedding capability share one inference boundary. No direct
legacy provider client remains; deterministic gates, approval, release and
manual authoring stay fully off the model path.

## What changed

- `agent/src/{main,structured}.mjs`: register `composer` and `linter`
  structured roles (schema selection + digest binding).
- `contract/agent/runtime-v1.schema.json` untouched; `protocol.rs` Role enum
  gains `Composer`/`Linter`; `supervisor.rs` manifest + completion validation
  bind the new schemas; `scripts/build-agent` and the test bundle builder ship
  `composer.schema.json`/`linter.schema.json`.
- `inference/roles.rs` is now the single chat-role runtime (Interviewer,
  Briefer, Composer, Linter): prof-g claim, packaged structured execution,
  per-role conditional validation and durable commit. `jobs::process` routes
  all four roles there.
- `jobs.rs`: deleted `ollama_chat`, `decode_chunks`, `provider_config`,
  `validate_endpoint`, `ollama_tags`, `ProviderConfig`, `OllamaChatResponse`
  and the legacy `/agent/provider` health fallback. `agent_provider` reads
  replaced by the profile store (`inference_profile` + qualification).
  `GET/PUT /agent/provider` and `POST /agent/provider/health` now surface only
  profile-backed settings and probe state.
- Admission pins the resolved prompt text and prompt version for chat roles
  (`application/interview.rs`, `application/brief.rs`,
  `application/compose_start.rs`, `writing.rs` linter) plus frozen profile
  revision, dependency digest and deadlines.
- `application/inference_context.rs` binds calibration to the qualified embed
  digest instead of `agent_provider`.
- `maintenance.rs` no longer treats `agent_provider` as portable; scrub drops
  the old provider UPDATE.
- `migrations/0034_remove_direct_provider_config.sql`: terminalizes
  unbound chat-role queues, drops `agent_provider`, verifies FK integrity.
- The debug-only native delegated fixture and its runtime hook were deleted;
  UCR authority suites now drive the packaged worker through a scripted
  upstream speaking the real Pi wire.

## Key tests

- `ar08_composer_and_linter_keep_approved_bytes_and_gate_deterministic`:
  compose/lint succeed through the worker; save blocked after template
  mutation; approval+release return exactly recorded bytes; zero provider
  calls after the terminal job.
- `ar08_model_cannot_approve_release_or_send`: host-invalid claim output is
  rejected (`OUTPUT_INVALID`), zero materials/approvals/releases.
- `ar08_all_roles_use_one_worker_boundary`: Interviewer, Briefer, Composer,
  Linter and an embed probe all run through the one profile; recorded
  upstream traffic is only `/api/version`, `/api/tags`,
  `/v1/chat/completions`, `/v1/embeddings`; no credentials leak; upstream
  refusal fails closed with a typed code.
- Browser: `ar08_author_reviews_generated_draft_from_selected_template`,
  `ar08_provider_failure_leaves_manual_gate_and_release_available` (mock +
  rust projects).
