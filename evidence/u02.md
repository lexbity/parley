## Contract and trace changes

- Added five operations to `contract/openapi.yaml` with exactly these
  `operationId`s: `startAgentRun`, `listAgentRuns`, `getAgentRun`,
  `getAgentRunTranscript`, `cancelAgentRun`. All are owner-session operations;
  the two mutations require a bounded `Idempotency-Key`. Every success and
  error response advertises `Cache-Control: private, no-store` and
  `X-Parley-Epoch`.
- Request/response schemas are closed (`additionalProperties: false`) with
  bounds: task 1..8192 bytes, 1..32 targets (IDs 1..200), 1..3 permissions,
  list/transcript `limit` 1..20, opaque cursors, path IDs 1..128. The error
  envelope is the shared typed `details` array form. Tier 1 read commands
  (`party.get_summary`, `opportunity.get_summary`) are documented as tool
  names; `commands__search`, `commands__describe` and `commands__run` are
  tool names, not HTTP operations.
- `web/src/api/generated.ts` was regenerated with the exact command
  `pnpm --dir web exec openapi-typescript ../contract/openapi.yaml -o src/api/generated.ts`
  and is byte-identical to the contract verifier's regeneration.
- Added 10 fixtures (valid + invalid for each of the five operationIds) and
  26 coverage rows. Every row carries all seven required fields and maps to
  the exact Rust or Playwright test IDs named in the U02 assignment.
